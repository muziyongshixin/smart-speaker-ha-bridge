# 已遇到的问题与修复

| 现象 | 案例中的处理 | 验证边界 |
|---|---|---|
| 小度 App 能开灯，语音说找不到 | 删除“开关 开关”等冗长名称，使用“客厅吸顶灯” | 真实灯验证通过 |
| 房间变成“家庭名 主卧” | Xiaomi Home 房间规则改为 room，合并/重命名已有 HA 区域 | 云端同步可能再次覆盖本地别名 |
| 湿度回答 0／重复 | Bemfa 把同房温度湿度合并发布，移除重复主题 | 客厅湿度语音已验证 |
| 问湿度却回答鱼缸／漏水 | 不把水温、水浸混入通用温湿度主题 | 数据仍留 HA |
| 小度全显示离线 | 分别检查 HA、云连接、虚拟指令、刷新与命名 | 当时恢复，但根因未完全隔离 |
| Huawei 无法读取 Android MAC | OneConnect 增加手动 MAC 字段，用本机真实 Wi-Fi MAC | 不使用 Android 占位 MAC |
| PIN 过期 | 重开配对窗口、在 App 完成新 PIN | 不复用过期 PIN |
| “打开客厅制热”找不到设备 | 华为开关别名改“暖冬”，制冷改“清凉” | 暖冬实测通过，清凉未实测 |
| 设备状态 unavailable | 修复源设备连接；不把 unavailable 编造成关闭或 0 | 不承诺所有米家设备支持 |

本方案依赖小米、巴法、华为云及社区集成，不是全本地方案。手机需常开、联网，Termux 后台不限制。监测电池发热与鼓包，使用适当充电策略。

未实现：刷成小爱、复制认证、修改唤醒词、任意歌名免费点播、HA→Sound SE DLNA 音乐。后者只有文档可行性研究，未部署。
